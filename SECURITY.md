# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in ilai-sentinel, please report it responsibly.

**Do NOT open a public GitHub issue.** Instead:

1. Email us at: security@ippocra.com
2. Describe the issue and include reproduction steps
3. Allow 48 hours for acknowledgment before following up

We will respond within 72 hours and work with you to resolve the issue.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |
